2. 앱 현황 — 지금 있는 것 (v3.0 "옷장 본전 게임")

기능상태
본전 게임 (핵심 차별화)✅ 완성 — 옷마다 회당 단가·본전 게이지, 옷장 회수율, "묶인 돈" 통계, 원탭 착용 기록. 경쟁사(에이클로젯 등)가 안 하는 영역
AI 캡쳐 등록✅ 완성 — 쇼핑 주문완료 스크린샷만 올리면 AI가 상품명·브랜드·가격 추출 → 자동 등록. 등록 마찰 3~7분 → 30초
AI 사진 등록✅ 사진 → 카테고리·색상·계절 자동 분류 (OpenAI Vision)
옷장 관리 기본기✅ 등록/편집/필터/즐겨찾기/인사이트(카테고리·브랜드·착용 통계)
착용 기록 + 캘린더✅ 날짜별 착장 기록, 스타일북, 코디 캔버스
날씨 기반 추천✅ 실시간 날씨 API + 옷장 연동 "오늘 뭐 입지"
구독 결제⬜ 미구현 — UI만 존재. RevenueCat 연동 예정 (수익화 1순위)
AI 어시스턴트 연결 (MCP)⬜ 설계 완료 — 유저가 자기 ChatGPT/Claude에 옷장을 연결 ("내 옷장 보고 짐 싸줘"). 국내 옷장 앱 중 최초 포지션
보관/리세일⬜ 로드맵 — 대출 자금으로 파일럿

3. 수익 모델 — 4단계

단계수익원단가/수수료시점
1프로 구독 — 무제한 옷장, 본전 리포트, AI 연결월 3,900~4,900원즉시 (결제 연동만 하면 됨)
2교체 추천 제휴 — "본전 끝·수명 끝" 순간의 추천 → 쿠팡·무신사 제휴 + 노브라블럼 크로스셀거래액 3~10%1~2개월
3리세일 연결 — "옷장에 묶인 돈" → 판매 위탁판매가 20~30%6개월
4계절옷 보관 구독 — 앱에서 신청, 보관 옷 자동 디지털화박스 월 7,900~12,900원파일럿 (자금 용도)

시너지 = 진짜 경제성: 노브라블럼 고객 DB → 앱 초기 유저 (CAC 0원) / 앱 → 노브라블럼 자사 광고 채널 (광고비 절감) / 보관 고객의 안 입는 옷 → 리세일 매물 (매입 원가 0원)

5. ★ 윤님이 오늘 밤 고민할 것들

  • ☐ ① 고용 계획 — 6억 받으면 1년차에 몇 명 뽑을 건가? 어떤 직군부터? (예: 개발 1, 마케팅/콘텐츠 1, 보관 운영 1) → 3년 후 총 몇 명? 퍼스트펭귄 평가에서 중요.
  • ☐ ② 보관 파일럿 공간 — 어디서 시작? 별감/심곡동 공간 일부 활용 가능? 아니면 신규 임차? 몇 평, 박스 몇 개 규모?
  • ☐ ③ 3개년 매출 목표 감각 — 1년차/2년차/3년차 매출 얼마라고 말할 건가? (앱 구독 + 제휴 + 보관 + 노브라블럼 합산. 내일 모델 같이 만들 때 윤님의 "감"이 출발점)
  • ☐ ④ 유저 목표 — 1년차 가입자 몇 명이 현실적? 노브라블럼 고객 DB가 몇 명인지 확인 (CAC 0원 스토리의 근거 숫자)
  • ☐ ⑤ 트렁크룸-노브라블럼 법적 구조 — 둘 다 법인 안에 있나? 매출 증빙을 법인 재무제표로 일원화할 수 있는지 (세무사 확인)
  • ☐ ⑥ 시연 시나리오 — 상담 때 폰으로 30초 시연: 캡쳐 등록 → 본전 게이지 → 묶인 돈. 어떤 옷/숫자가 인상적일까?
  • ☐ ⑦ 영업점 — 어느 지점으로 갈지, 기존 거래 은행(보증서 대출 실행 은행)은 어디로 할지
  • ☐ ⑧ 재무제표 — 2024·2025 결산 재무제표 준비 상태 확인 (세무사에게 요청)
